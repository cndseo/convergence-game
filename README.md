# CONVERGENCE — La rue s'éveille

Jeu tactique indépendant, jouable sur mobile et ordinateur. Prototype de fiction, affrontements non graphiques.

- Source du jeu : `index.html` (HTML/CSS/JS sans dépendance)
- Serveur : Node.js standard, `npm start`, port `PORT` ou 3000
- Sauvegarde : localStorage dans le navigateur
- Vérification santé : `/health`

## Tester

`npm start` puis ouvrir `http://localhost:3000`.

## Déploiement

Railway depuis `main`, mode Railpack/Node. Aucun secret requis.
